# Project Docs

Course digital garden: an offline-first PWA built with Quartz v5, published to GitHub Pages, fed by Obsidian-compatible Markdown converted from the course's DOCX, PDF and PPTX files.

| Doc | What it covers |
|---|---|
| [architecture.md](architecture.md) | System overview, components, repo layout |
| [ingest-pipeline.md](ingest-pipeline.md) | Converting source files to Markdown, tagging and linking concepts, the PR review flow |
| [pwa-offline.md](pwa-offline.md) | Service worker, caching, updates, iOS/Android specifics |
| [quartz-upgrades.md](quartz-upgrades.md) | How Quartz is vendored and how to upgrade it |
| [decisions.md](decisions.md) | Decision log: what we chose and why |
| [roadmap.md](roadmap.md) | Phases, status, open questions |

When a decision changes, add a new entry to `decisions.md` that supersedes the old one rather than editing history.
